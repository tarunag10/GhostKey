# GhostKey Privacy Policy

Last updated: May 15, 2026

GhostKey is a browser extension that suppresses intrusive login popups and restores page usability.

## Data Collection

GhostKey does not collect, sell, rent, or share personal data.

The extension stores settings locally in Chrome storage, including whether GhostKey is enabled globally, whether aggressive mode or debug mode is enabled, and which sites the user has disabled or allowlisted.

## Page Access

GhostKey runs on web pages so it can detect intrusive login overlays, scroll locks, blurred page content, and backdrops. This page access is used to identify and suppress blockers directly in the browser.

GhostKey does not transmit page content to a remote server.

## Network Requests

The checked-in GhostKey extension code does not include analytics, advertising, tracking, or remote API calls.

## User Controls

Users can disable GhostKey on individual sites from the popup, add sites to the allowlist in Settings, turn off GhostKey globally, and undo the last suppression action.

## Contact

For privacy or support questions, contact the developer through the support channel listed on the Chrome Web Store listing.
